# Support

Use the correct channel so maintainers can respond safely and efficiently.

| Need | Where to start |
|---|---|
| Installation, Termux, language usage, examples, or documentation question | Read the [README](README.md), [documentation index](docs/README.md), and [examples](examples/README.md), then open a GitHub discussion or issue if the answer is missing. |
| Reproducible compiler, CLI, LSP, grammar, or extension bug | Use the GitHub bug-report form with Padma version, Termux/device or OS details, minimal `.pd` source, expected result, actual result, and command output. |
| New syntax, standard library API, platform target, or compatibility proposal | Use the feature-request form and explain the problem before proposing syntax. |
| Security concern | Follow [SECURITY.md](SECURITY.md); do not use a public issue. |
| General code contribution | Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request. |

Never share passwords, API tokens, session cookies, private source code, or personal data in an issue, discussion, or log.
