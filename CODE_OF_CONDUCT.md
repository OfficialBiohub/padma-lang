# Code of Conduct

Padma is built for Bangladeshi learners and contributors from the wider programming community. We expect discussion to be respectful, accessible, technically honest, and welcoming across language, nationality, gender, experience level, disability, faith, and identity.

Constructive disagreement about language design is welcome. Harassment, insults, discrimination, sexualized language, threats, doxxing, spam, deliberate misinformation, or pressure to add unsafe behavior is not acceptable.

Maintainers may edit, remove, or reject contributions and discussions that violate these expectations. Repeated or serious violations may result in participation restrictions. Report concerning behavior privately through the maintainer contact route in the repository owner profile; do not post sensitive personal information in public issues.

This policy applies to repository discussions, issues, pull requests, review comments, and project-related community spaces.
